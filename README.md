📊 Global Unemployment Analysis & Prediction Using Machine Learning

📌 Overview

This project analyzes global unemployment trends using historical data from the World Bank. It explores unemployment changes over time, examines the impact of COVID-19, compares the latest five-year period, and uses Machine Learning to predict the unemployment rate for 2026.

🎯 Objectives

- Analyze historical global unemployment trends
- Examine the impact of COVID-19 on unemployment
- Compare unemployment rates from 2021–2025
- Visualize unemployment trends
- Build a Linear Regression model
- Evaluate model performance
- Predict the unemployment rate for 2026

🛠️ Tools & Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- World Bank API

🤖 Machine Learning

A Linear Regression model is trained using historical unemployment data.

The dataset is divided into:

- Training data: Historical data up to 2022
- Testing data: 2023–2025
- Prediction: 2026

The model is evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

📈 Analysis

The project includes:

- Historical unemployment trend visualization
- COVID-19 period analysis
- Five-year comparison
- Actual vs. predicted values
- Future unemployment prediction

📂 Data Source

World Bank

Indicator: Unemployment, total (% of total labor force) — modeled ILO estimate

The data is collected directly through the World Bank API.

⚠️ Note

The 2026 value generated by the model is a prediction, not an official unemployment rate. Linear Regression is used as a simple baseline model for learning and demonstration.
